# AirMonitor

یه اپ ساده اندرویدی: ایرپاد (یا هر هدست بلوتوثی) رو کنار مادرت می‌ذاری به عنوان میکروفون،
گوشی پیش خودت صدا رو **زنده از بلندگوی خودش پخش می‌کنه** و همزمان **روی حافظه ضبط** می‌کنه.

## قبل از هر چیز — محدودیت‌های مهم

1. **کیفیت صدا:** روی اندروید، AirPods فقط به عنوان یه هدست بلوتوث معمولی (پروتکل HFP)
   شناخته می‌شه، نه با کیفیت کامل اپل. یعنی صدای میکروفون شبیه تماس تلفنیه
   (نسبتاً کدر و کم‌کیفیت‌تر از ضبط معمولی)، نه کیفیت موسیقی.
2. **برد:** محدود به برد بلوتوث همون ایرپادهاست؛ با فاصله زیاد یا چند دیوار ممکنه
   قطع و وصل بشه یا اصلاً وصل نمونه.
3. **باتری:** هم گوشی و هم ایرپاد سریع‌تر از حالت عادی تخلیه می‌شن.
4. **اکو/فیدبک:** اگه گوشی که صدا رو پخش می‌کنه نزدیک ایرپاد مادرت باشه، ممکنه صدای
   پس‌زمینه عجیب (اکو) بشنوی. این دو تا رو از هم دور نگه دار.

## نکته حریم خصوصی / قانونی

این اپ داره صدای یه نفر دیگه (مادرت) رو بدون اینکه خودش دکمه‌ای بزنه ضبط و پخش می‌کنه.
بهتره از قبل بهش بگی که گوشی/ایرپاد برای همین کار اونجاست، مخصوصاً اگه ضبط‌ها رو
جایی نگه می‌داری یا نشون می‌دی. بسته به کشور/ایالتی که توش هستی، ضبط صدای کسی
بدون اطلاعش ممکنه از نظر قانونی مسئله‌ساز باشه.

## روش بدون کامپیوتر (فقط با گوشی)

پروژه از قبل یه فایل `.github/workflows/build.yml` داره که با GitHub Actions
به صورت خودکار APK رو می‌سازه — یعنی فقط با مرورگر گوشی هم می‌شه این کارو کرد:

1. با مرورگر گوشی وارد [github.com](https://github.com) شو و یه اکانت رایگان بساز (اگه نداری).
2. یه ریپازیتوری جدید بساز (دکمه سبز "New").
3. تو همون صفحه ریپازیتوری، "uploading an existing file" رو بزن و همه فایل‌های
   داخل پوشه `AirMonitor` (شامل پوشه مخفی `.github`) رو آپلود کن و Commit بزن.
4. برو به تب **Actions** بالای صفحه؛ اگه خودش شروع نشد، روی workflow
   "Build APK" بزن و دکمه "Run workflow" رو بزن.
5. چند دقیقه صبر کن تا سبز بشه، بعد پایین همون صفحه، تو بخش **Artifacts**
   فایل `AirMonitor-debug-apk` رو دانلود کن (یه zip هست، APK توشه).
6. فایل apk رو با یه اپ مدیریت فایل (یا Files خود اندروید) باز کن؛ گوشی ازت
   اجازه "نصب از منابع ناشناس" برای همون اپ (مرورگر/فایل‌منیجر) رو می‌خواد،
   بدش و نصب کن.

این روش کاملاً روی سرورهای گوگل/مایکروسافت اجرا می‌شه، نیازی به کامپیوتر خودت
یا فیلترشکن نداره (گیت‌هاب معمولاً از ایران در دسترسه).

## چطور با کامپیوتر بسازمش (روش معمول)

1. [Android Studio](https://developer.android.com/studio) رو نصب کن.
2. این پوشه (`AirMonitor`) رو با Android Studio باز کن (File → Open).
3. صبر کن Gradle Sync تموم بشه (نیاز به اینترنت داره تا کتابخونه‌ها دانلود بشن).
4. گوشی اندرویدت رو با کابل USB وصل کن و حالت **USB debugging** رو از تنظیمات
   Developer Options روشن کن، یا مستقیم از Android Studio دکمه Run (▶) رو بزن.
5. اپ به اسم «AirMonitor» روی گوشی نصب می‌شه.

## نحوه استفاده

1. ایرپاد رو از تنظیمات بلوتوث گوشی (همون گوشی‌ای که اپ روشه) پیر کن و وصل کن.
2. ایرپاد رو کنار مادرت بذار (تو اتاقش).
3. اپ AirMonitor رو باز کن، دسترسی‌های میکروفون/بلوتوث/نوتیفیکیشن رو که می‌خواد، بده.
4. دکمه «شروع پایش» رو بزن. وقتی وصل شد، صدا بلافاصله از بلندگوی گوشی خودت پخش می‌شه.
5. برای توقف، دکمه «توقف پایش» رو بزن.
6. دکمه «پخش آخرین ضبط» آخرین فایل ذخیره‌شده رو برات پخش می‌کنه.

فایل‌های ضبط‌شده (فرمت WAV) اینجا ذخیره می‌شن:
`Android/data/com.example.airmonitor/files/Recordings`
(از اپ «فایل‌ها»/Files روی گوشی قابل دسترسیه.)

## اگه چیزی کار نکرد

- اگه بعد از «شروع پایش» وضعیت رو «ناموفق» نشون داد، مطمئن شو ایرپاد واقعاً به
  **همون گوشی** وصله (نه گوشی دیگه).
- بعضی گوشی‌ها/نسخه‌های اندروید محدودیت‌های سخت‌گیرانه‌تری رو پس‌زمینه دارن؛ اگه
  اپ خیلی زود قطع شد، مطمئن شو تنظیمات «بهینه‌سازی باتری» برای AirMonitor خاموشه
  (Settings → Apps → AirMonitor → Battery → Unrestricted).
